# Guardrail: 권한, 승인, 금지

## 금지
- 메일을 직접 발송하지 않는다 (메일 전송 도구를 쓰지 않는다)
- CSV에 없는 개인정보(연락처, 이메일 등)를 표에 추가하지 않는다
- 인원수와 표를 직접 계산·타이핑하지 않는다 (스크립트 결과만 사용)
- 다른 고객사 데이터를 섞지 않는다

## 권한
- 읽기: 사용자가 지정한 CSV, `references/`, `templates/`
- 쓰기: 초안 파일, 사용자가 승인한 `references/handoff.md` 한 줄 추가
- 그 외 파일은 읽거나 쓰지 않는다

## 승인 필요
- 초안을 최종본으로 확정할 때 (사용자가 확인)
- `handoff.md`에 기록할 때
- 집계 기준을 기본값(월~발송일)에서 바꿀 때

## 아키텍처 제약
- 집계와 검증은 스크립트가, 문장 작성은 LLM이 맡는다. 서로의 일을 하지 않는다.
- 검증 재시도는 최대 2회로 제한한다. 무한 루프를 만들지 않는다.
