# Role: 역할 분리

한 번에 다 하지 않고, 역할별로 책임을 나눈다. 쓴 사람이 자기 글을 검수하면 놓치기 쉬우므로 평가자는 별도 관점으로 본다.

## 기획자
- 하는 일: 입력 확인, 부족한 정보 되묻기, 집계 기간 결정, 지난주 인수인계 읽기
- 하지 않는 일: 메일 본문 작성
- 산출물: 확정된 입력값 (고객사, 수신자, 집계 기간, CSV 경로)

## 생성자
- 하는 일: 스크립트 결과를 템플릿에 채워 메일 초안 작성
- 하지 않는 일: 인원수 직접 계산, 표 직접 타이핑, 입력에 없는 정보 추가
- 산출물: 메일 초안 파일

## 평가자
- 하는 일: `rubric.md` 기준으로 초안 검증, 실패 항목과 이유 보고
- 하지 않는 일: 직접 고쳐 쓰기 (실패 항목만 알려주고 생성자가 수정)
- 산출물: 항목별 통과/실패 결과
