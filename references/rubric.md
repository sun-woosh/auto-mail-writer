# Rubric: 합격 기준

모든 항목을 통과해야 합격이다. 자동 항목은 `scripts/verify_draft.py`가, 수동 항목은 평가자가 확인한다.

## 자동 검증 (verify_draft.py)
- [ ] 본문의 "총 N명"이 스크립트 집계(COUNT)와 일치한다
- [ ] 표의 데이터 행 수가 COUNT와 일치한다
- [ ] 표가 본문에 직접 들어 있다 (0명이면 표 없음)
- [ ] 제목에 고객사명이 들어 있다 (`--customer` 지정 시)
- [ ] 남은 `{플레이스홀더}`가 없다

## 수동 검증 (평가자)
- [ ] 집계 기간이 제목·본문에 명시되어 있다
- [ ] 수신자 호칭이 맞다 (`customers.md` 기준)
- [ ] 표에 지난주 등록자나 중복 인원이 없다
- [ ] 입력에 없는 개인정보를 추가하지 않았다
- [ ] 오탈자가 없고 톤이 `customers.md`와 맞다

## 실패 시
실패 항목만 고쳐 재검증한다. 최대 2회, 그래도 실패하면 사용자에게 그대로 보고한다.
